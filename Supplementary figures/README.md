# Supplementary figures

From MATLAB, change to this directory first.

```matlab
make_supplementary_figures
make_transition_quartile_figures
```

`make_supplementary_figures` writes:

- `FigureS_BCR_flowMRD.png`
- `FigureS_T4_T5_T6.png`

`make_transition_quartile_figures` reads `../Figure4/Data` and `../Figure6/Data/PB_BM_merged_with_MRDflow_BCR.csv` and writes the quartile PNG panels already present in this folder.

`FigureS1.png`, `FigureS2.png`, `FigureS3.pdf`, and `supplementary material.pdf` are the packaged supplementary panels.
